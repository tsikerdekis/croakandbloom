## Notes

The first two carry a public-domain tag on Commons (they are simple typographic
wordmarks that fall below the threshold of originality). The Washington Wedding
Day mark is not on Commons; it was taken from the publication's own site.

Nominative use of a publication's logo to state that you were featured in it is
generally acceptable, but it is not a blanket permission. If the studio wants to
be careful, keep the "Featured in" label adjacent to the marks (as the layout
does) so the relationship reads as attribution rather than endorsement.

## Editing

Each file has been stripped of editor metadata and has every `fill` rewritten to
`currentColor`, so the marks inherit `color` from CSS instead of being hard-coded
black. Sizing is by height in `_sass/_components.scss` (`.press__logo--*`) to
match their optical weight; widths stay `auto` so the intrinsic aspect ratios
govern.
